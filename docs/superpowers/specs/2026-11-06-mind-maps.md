## The idea

A professional mind map system inside si: one Markdown list per map, maps
that open into other maps with a click and a zoom, styles for the lines and
the topics, themes, and the same map as a page, inside an article or a
tutorial, or on a slide.

## Founder decisions (2026-11-06)

1. **Structure:** separate files per map is the main structure; one big file
   with maps separated by `---` (each `# Title {#id}`) is accepted too.
2. **Layout:** both automatic layout and free positioning (drag a single
   topic, its lines stretch; Shift-drag a branch; the canvas pans).
3. **Animation:** as much as possible: grow-in, zoom drill-down, flow on the
   lines, pulses, Play.
4. **Import and export:** yes (SVG, PNG, PDF; OPML, FreeMind, XMind, Mermaid).
5. **Version:** 2.0.0 when the builder (web and desktop Studio) is in.
6. Keep every mockup feature and every theme.

## Format

Markdown, not JSON: a nested list is a mind map, diffs well, agents write it,
and without JavaScript it is still a readable list.

```markdown
---
type: mindmap
layout: map            # map | right | org | radial
lines: curved          # curved | straight | orthogonal | tapered
nodes: box             # box | pill | underline
map-theme: auto        # auto | harbor | blueprint | ink | garden
watermark: Northwind Logistics
watermark-position: corner   # corner | across
---
# The Thursday Promise

- Checkout {badge=Thu}
  - Payment → payments.md            # another map: drill-down (inlined)
  - Refunds → #refunds               # a map of this file
  - Label → slides: talk.md#7        # a slide
  - Dusk ![](img/dusk.jpg)           # a picture
  - [!sticky] Ask ops.               # a sticky note
  - Moved {pos=40,-12}               # moved by hand (branch-pos= for a branch)
```

A fenced code block inside an item is a code topic. The fence form:
```` ```mindmap layout=right lines=tapered theme=harbor ````.

## Shipped in v1.12.0

- Page type and fence; four layouts (phone portrait falls back to `right`),
  four line styles, three node styles, five map themes (`--si-mm-*` tokens).
- Topics: badges, collapsed, pictures, sticky notes, highlighted code, links
  to maps, slides, pages and URLs; positions by hand.
- Drill-down with zoom and breadcrumb; linked map files inlined (cycles too).
- Reading: fold, drag, Shift-drag, arrows, pan, zoom, Fit, Tidy; on a page `/`
  search across every map and Play (overview, then one branch per step).
- Watermark in the map (corner or across).
- Terminal: trees in `si play --terminal` and `si --terminal`.
- Studio: "New mind map" on the web, the desktop app and the terminal; the
  preview draws the map.
