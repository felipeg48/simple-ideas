How it works in si

      

        
One fence, one window. Options on the fence line pick the window, the theme, the backdrop and the line numbers; nothing else changes in the Markdown.

        
Callouts are placed by hand. Drag a note anywhere; si writes its place back as at=, so the next build puts it in the same spot.

        
A show is a run of fences with the same id=. On slides each one is a click; lines that stay glide, new ones fade in, like the canvas morph between slides.

        
Anywhere a fence goes. On a slide it fills the figure, and across consecutive slides the same id= morphs as the slide changes. In a tutorial or an article it sits in the text, with ← → under it. In a mind map, a code topic can wear the same window.

        
Exports: an animated GIF of the whole show, or one PNG or SVG per step, framed with the backdrop.
