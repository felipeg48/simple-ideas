title: Examples
description: Working files to copy from, the same ones si --export example writes.
---

Every example is a real document, not a template: a talk about one order's
journey, the article and the tutorial that go with it, a site, mind maps and
code shows. Write them all into a folder and open them live:

```bash
si --export example --type all -o si-examples
si play si-examples --open
```

| Example | What it shows |
|---|---|
| [`showcase.md`](https://github.com/felipeg48/simple-ideas/blob/main/examples/showcase.md) | every slide rule in one talk |
| [`article/retry.md`](https://github.com/felipeg48/simple-ideas/blob/main/examples/article/retry.md) | an article with code windows and a 3D bricks mind map |
| [`guide/`](https://github.com/felipeg48/simple-ideas/tree/main/examples/guide) | a tutorial with steps, callouts and a runbook |
| [`site/`](https://github.com/felipeg48/simple-ideas/tree/main/examples/site) | a site with a navigator, cards and embeds |
| [`mindmap/`](https://github.com/felipeg48/simple-ideas/tree/main/examples/mindmap) | linked mind maps in 2D, 3D blocks and toy |
| [`code/retry.md`](https://github.com/felipeg48/simple-ideas/blob/main/examples/code/retry.md) | a code show in macOS, Windows and terminal windows |
