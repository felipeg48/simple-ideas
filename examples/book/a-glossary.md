# Glossary

| | |
|---|---|
| **Hand-off** | An event one station writes and the next one reads. |
| **Idempotency key** | The order id, sent with every payment call, so the bank never charges twice. |
| **Promise** | The delivery day printed at checkout and shown on the tracking page. |
| **Wave** | A group of vans that leave the warehouse together. |
