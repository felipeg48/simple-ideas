# What a browser does

A web page starts as a plain text file on a computer somewhere else. When you
type an address, your browser asks that computer for the file, reads it from
top to bottom, and draws what it describes. Everything you see, from the
headline to the colour of a button, comes from instructions in text.

## Three languages, three jobs

| | |
|---|---|
| **HTML** | what is on the page: headings, paragraphs, links, pictures |
| **CSS** | how it looks: colours, sizes, spacing, layout |
| **JavaScript** | what it does when you click, type or scroll |

This course covers the first two. They are enough to publish a page that
reads well on a phone and on a wide screen.

## The browser is forgiving

A browser never refuses a page. When a tag is left open or a rule is
misspelled, it guesses what you meant and draws its best attempt. That is kind
to beginners, and it also means a mistake can hide for a long time. The labs
show you where to look when the page does not look the way you expect.

> [!TIP]
> Keep the browser and your editor side by side. Save, then reload: the
> page you see is always the file as it was when you last saved it.
