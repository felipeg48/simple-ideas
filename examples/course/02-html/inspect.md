# Inspect a page live

## What this demo must accomplish

1. **The page is a tree.** The room sees the elements nested in the
   Elements panel.
2. **Changes are local.** Editing a heading in the tools changes only this
   browser's copy, and a reload brings the original back.

## Steps

### 1. Open the tools (2 min)

Open any article page, right-click the headline and choose Inspect.

> Say: "Every page you visit can be opened up like this. Nothing here is secret: it is the same file your browser was sent."

### 2. Edit a heading (3 min)

Double-click the text of the `h1` in the Elements panel and type a new
headline.

> Say: "I just changed the news. Only on this laptop, and only until I reload."

### 3. Reload (1 min)

Press reload and point at the original headline.

```text
The original headline is back.
```

## If it goes wrong

- **The tools open docked too small:** undock them into their own window.
