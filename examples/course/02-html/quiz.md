# Check yourself

## Which tag makes the largest heading?
- [x] `<h1>`
- [ ] `<h6>`
- [ ] `<head>`
> Explanation: `h1` to `h6` are headings, `h1` the most important; `head` holds the page's settings, not its content.

## Where does the `title` element go?
- [ ] Inside `body`
- [x] Inside `head`
- [ ] Before `<!doctype html>`
> Explanation: the title belongs to the page's settings, so it sits in `head`; the browser shows it on the tab.

## Which of these are block elements, each starting on a new line?
- [x] `<p>`
- [ ] `<em>`
- [x] `<ul>`
- [ ] `<a>`
> Explanation: paragraphs and lists are blocks; emphasis and links flow inside a line of text.

## What does the `href` attribute of a link hold?
- [ ] The text of the link
- [x] The address the link leads to
- [ ] The colour of the link
> Explanation: `href` is the address; the text goes between the tags, and the colour comes from CSS.
