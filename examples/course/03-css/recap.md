## Structure, then style

- **HTML** says what each part is: a heading, a paragraph, a link
- **CSS** says how it looks: colour, size, space
- The **cascade** picks one value when several rules match

Notes: HTML says what each part of the page is. CSS says how it looks. And when several rules match the same element, the cascade picks the one that wins. [CLICK]

Points:
- Three ideas, one per line
- The cascade is the one people forget
