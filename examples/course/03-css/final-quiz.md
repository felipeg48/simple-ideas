# Final check

## Which selector picks every element with `class="note"`?
- [ ] `note`
- [x] `.note`
- [ ] `#note`
> Explanation: a dot selects by class; a hash selects by id.

## Two rules of the same specificity set `color` on `h2`. Which one wins?
- [ ] The first one written
- [x] The last one written
- [ ] Neither: the browser uses black
> Explanation: with equal specificity, the rule written later wins.

## Which property keeps a column of text at a readable width?
- [ ] `line-height`
- [ ] `font-family`
- [x] `max-width`
> Explanation: `max-width` stops the column from growing past a comfortable measure.
